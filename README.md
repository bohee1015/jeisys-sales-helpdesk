# 영업 지원 헬프데스크 챗봇

영업사원이 Teams·전화·카카오톡으로 흩어져 보내던 업무 요청을 챗봇 한 곳으로 모으는 사내 헬프데스크입니다.
자연어로 요청을 입력하면 카테고리를 자동으로 분류하고, 필수값이 빠지면 되묻고, 선행 업무(예: 기안 승인)가
필요한 요청은 먼저 확인한 뒤 영업관리팀에 접수합니다.

## 해결하려는 문제

영업사원 약 20명의 문의를 영업관리팀 1명이 전담 처리하다 보니, 요청이 여러 채널로 흩어져 누락되고
같은 질문에 반복 응대하는 비효율이 있었습니다. 이 서비스는 접수 창구를 하나로 모으고, 반복 질문은
FAQ로 즉시 답하며, 처리 현황을 한곳에서 볼 수 있게 합니다.

## 주요 기능

- **자연어 요청 접수**: 평소 메신저에 쓰던 문장을 그대로 입력하면 대분류/소분류로 자동 분류합니다.
  분류가 애매하면 임의로 단정하지 않고 사용자에게 직접 고르게 합니다.
- **필수값 되묻기**: 소분류별 필수 항목(거래처명, 일정, 수량 등)이 빠지면 챗봇이 하나씩 되묻습니다.
- **선행 업무 확인**: 선행 조건이 등록된 요청은 완료 여부를 먼저 확인하고, 미완료면 진행하지 않고 안내합니다.
- **요청 분리 접수**: 한 메시지에 서로 다른 업무가 "및/그리고"로 이어지면 2건으로 나눠 접수합니다.
- **음성 입력**: 외근·이동 중 타이핑이 어려울 때 마이크 버튼으로 말하면 텍스트로 입력됩니다.
  (브라우저 내장 Web Speech API, 한국어)
- **FAQ**: 자주 묻는 질문을 검색하고, 관리자가 직접 등록·수정·삭제합니다.
- **접수 이력**: 본인이 접수한 요청과 전체 대화 원문을 확인합니다.
- **관리자 화면**: 요청접수관리 / FAQ 관리 탭으로 나뉘며, 요청의 처리 상태(요청등록 → 처리중 → 완료)를
  지정하고 상태별·요청자별·완료처리자별·카테고리별로 조회합니다. 완료 처리 시 담당자와 시각이 기록됩니다.

## 기술 스택

- [Next.js 16](https://nextjs.org) (App Router) + React 19 + TypeScript
- Tailwind CSS v4
- Supabase (인증 · PostgreSQL · RLS)
- Vercel 배포

분류 로직은 외부 LLM 없이 키워드·정규식 기반으로 동작합니다(`app/lib/nlp.ts`).

## 폴더 구조

```
app/
  api/            요청·FAQ·채팅 API 라우트
  admin/          관리자 화면 (요청접수관리 / FAQ 관리)
  components/     챗봇, 음성 입력 버튼 등 공용 UI
  lib/            분류·필드 추출·데이터 접근 로직
  faq/ history/   FAQ, 접수 이력 화면
supabase/
  migrations/     helpdesk 스키마 마이그레이션
proxy.ts          인증 미들웨어 (Next.js 16부터 middleware.ts 대신 proxy.ts)
```

## 로컬 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

### 환경 변수

프로젝트 루트에 `.env` 파일을 만들고 Supabase 프로젝트 값을 넣습니다.

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

`.env`는 `.gitignore`에 포함되어 저장소에 올라가지 않습니다.

### 데이터베이스

`supabase/migrations/`의 마이그레이션이 `helpdesk` 스키마(`helpdesk.requests`, `helpdesk.faqs`)를 만듭니다.
요청 데이터는 RLS로 보호되어 **요청자 본인과 관리자만** 조회할 수 있습니다.

### 무이자리스 견적서 양식

견적서 엑셀 생성 기능은 `templates/lease-quote-template.xlsx`를 읽어 값을 채웁니다.
이 양식에는 회사 직인과 사업자 정보가 들어 있어 **저장소에는 포함하지 않습니다.**
사내 원본 양식이 있다면 아래 명령으로 만들 수 있습니다 (거래처 목록 등 내부 시트는 자동으로 제거됩니다).

```bash
node scripts/build-lease-template.cjs "<사내 무이자 리스 견적서 양식.xlsx 경로>"
```

## 보안

저장소의 예시 데이터(`app/lib/samples.ts` 등)에 나오는 병원명·인명·연락처는 모두 가명입니다.


사내 업무 데이터를 다루므로 로그인한 사용자만 접근할 수 있으며, 권한 판단은 서명 검증이 이루어지는
`supabase.auth.getClaims()`로 합니다. API 키 등 민감 정보는 코드에 두지 않고 환경 변수로만 관리합니다.
